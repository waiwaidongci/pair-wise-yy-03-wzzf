# SceneForge 浏览器三维场景编辑器

技术栈：React、TypeScript、Vite、Three.js、React Three Fiber、Drei、Zustand、MUI、Leva。

## 功能

- 添加程序化几何体、灯光和透视相机，不依赖外部模型。
- 在层级树中拖拽对象建立或取消父子关系，并跟随父级变换。
- 使用移动、旋转、缩放控件编辑对象，支持步长吸附和三轴对齐。
- 编辑材质颜色、粗糙度、金属度、透明度、线框和阴影参数。
- 场景保存为 JSON 并可重新加载。
- 提供 InstancedMesh 批量渲染模式，可添加 240 个对象进行压力验证。

## 组合件（Prefab）与引用实例

针对"同一套展台反复摆放、改一处要逐个再摆"的问题：

- **制作组合件**：在层级树 Shift 多选一组对象，点击「把选中的对象做成组合件」，
  选中物被烘焙成一个组合件模板，并就地替换为一个引用实例。
- **放置引用**：组合件库里点击即可在场景中放置更多引用实例；实例只存摆放与私有覆盖，不复制模板数据。
- **源改动传播**：双击组合件（或点实例上的编辑按钮）进入源编辑；源一改，
  所有**没有单独调过**该属性的实例自动重算。
- **私有覆盖保留**：直接在实例内部件上调的位置 / 旋转 / 缩放 / 可见 / 材质（按属性粒度）
  会存为该实例的 override，源改动盖不掉；检查器里每个被覆盖的属性都能一键「恢复跟随源」。
- **嵌套成环防护**：组合件模板里可以放别的组合件引用；若会形成 A→B→A 的嵌套环，
  操作入口直接拦截，解析器也会在数据异常时截断并提示而不是死循环。
- **旧数据升级**：无组合件信息的 v1 / 无版本 JSON 会先经 `migrateDocument` 升级到 v2（补 `prefabs`
  与缺失字段）再读入。
- **分批渲染 + 失败恢复**：解析后节点数超过阈值时按父子深度分批、逐帧挂载，显示进度；
  渲染期异常由错误边界捕获，回滚到上一次成功渲染的现场（对象、组合件、选择、相机机位）后重挂。

### 数据结构要点

- `SceneDocument.version = 2`，新增 `prefabs: PrefabAsset[]`。
- 实例句柄是 `type: 'group'` 且带 `instanceOf`（指向组合件 id）的场景对象；
  `overrides` 按 `nodePath`（模板节点路径）存放字段级覆盖，材质再按属性粒度合并。
- 解析器 `resolveScene(objects, prefabs)` 把场景展平为 `ResolvedNode` 森林供渲染，
  相关纯函数见 `src/utils/prefabs.ts`，分批计划见 `src/utils/renderBatches.ts`。
